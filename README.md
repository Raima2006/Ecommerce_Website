# 🛒 ShopSphere - A Clothing Website
ShopSphere is a lightweight, PHP-based e-commerce web application. It features a complete user authentication system, a product browsing interface, and a functional checkout process.
<hr>
🚀 Features
User Authentication: Secure Login and Sign-up system with Gmail-specific validation.

Responsive Design: A clean, modern UI that works on both desktop and mobile devices.

Form Validation: Client-side and server-side checks for email formats and password requirements.

Checkout System: A comprehensive billing and payment details form.

Session Management: Keeps users logged in while they shop and allows for secure logout.

Database Integration: Stores user data and order information using MySQL.
<hr>
🛠️ Tech Stack
Frontend: HTML5, CSS3, JavaScript (Glide.js for sliders, Boxicons for iconography).

Backend: PHP.

Database: MySQL.

Tools: XAMPP/WAMP (Local Server).
